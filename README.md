# ربات تلگرام تحلیل بازار ایران

این نسخه به‌جای TwelveData از API سرویکس (Servix) برای دریافت داده بازار استفاده می‌کند.

## بازارهای فعال

- دلار
- یورو
- طلای ۱۸ عیار
- مثقال طلا
- سکه امامی
- سکه بهار آزادی
- بیت‌کوین
- اتریوم
- تتر

کد بازارها در `config.py` قرار دارند و در صورت نیاز قابل تغییر هستند.

## نصب

```bash
pip install -r requirements.txt
```

سپس `.env.example` را به `.env` تبدیل کنید و این دو مقدار را وارد کنید:

```env
TELEGRAM_BOT_TOKEN=...
SERVIX_API_KEY=...
```

کلید API را داخل کد، URL یا GitHub قرار ندهید.

## اجرا

```bash
python bot.py
```

## دستورات ربات

- `/start`
- `/markets`
- `/history طلا`

برای هر بازار، ربات داده OHLC را دریافت می‌کند و بر اساس RSI، MACD و SMA20/SMA50 تحلیل خودکار و نمودار تولید می‌کند.

این ربات معامله واقعی انجام نمی‌دهد و خروجی آن توصیه مالی نیست.

منبع داده: Servix
